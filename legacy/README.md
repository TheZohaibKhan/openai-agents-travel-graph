# Legacy prototype (archived)

This folder holds the **first, unfinished version** of the project (an "OpenAI Agents SDK + LangGraph +
browser automation" design). It was never fully working: most agents were demo stubs that ignored the AI's
answers, and the browser/research tools were never connected.

It is kept only for reference and **cannot be run from here** (its imports expect to live at the project root).
The working version is in the `travel_planner/` folder one level up.
